¿Cómo manejamos los estilos?

El proyecto usa Tailwind 4. El handoff trae un CSS completo listo para copiar.

A

CSS Module separado (recomendado por el handoff)

Copiar styles.css como bxi.module.css y usarlo en los componentes nuevos. Tailwind sigue siendo para el resto de la app.

Pros

  • Implementación más rápida
  • CSS ya validado por diseño
  • Cero riesgo de drift visual

Contras

  • Dos sistemas de estilo en el proyecto
  • Difícil de extender con Tailwind después
B

Reescribir a Tailwind 4

Convertir todos los estilos del handoff a clases de Tailwind. Los tokens de diseño van en globals.css como CSS variables.

Pros

  • Consistencia con el resto del proyecto
  • Más fácil de mantener a futuro

Contras

  • Más trabajo de conversión
  • Riesgo de diferencias visuales sutiles
